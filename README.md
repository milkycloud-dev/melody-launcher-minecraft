# 🎮 NoteBuns Launcher

Официальный лаунчер сервера **NoteBuns**. Скачал, ввёл ник, нажал «Играть» — всё остальное лаунчер сделает сам.

**[⬇️ Скачать последнюю версию](https://github.com/milkycloud-dev/melody-launcher-minecraft/releases/latest)**

## ✨ Что умеет

- ☕ **Java уже внутри** — ставить ничего не нужно
- ⚡ **Быстрая синхронизация** — скачивается только то, что изменилось
- 💾 **Настройки не сбрасываются** — бинды, шейдеры и ресурспаки остаются на месте
- 🎙 **Моды помнят настройки** — Voice Chat, эмодзи и другие переживают обновление сборки
- 🔄 **Тихое автообновление** — без консольных окон
- 🧠 **Умная память** — подбирает объём под вашу систему
- 📂 **Перенос на другой диск** — папка игры переезжает без потери файлов
- 🛡 **Честная игра** — защита от читерских текстур
- 💻 **Windows, macOS и Linux**

## 📥 Установка

### 🪟 Windows

Скачайте `.exe` и запустите. Ярлык появится на рабочем столе.

<details>
<summary><b>⚠️ Появилось окно «Windows защитила ваш компьютер» (SmartScreen)</b></summary>

<br>

Так бывает у новых программ, которые Windows видит впервые — она пока не набрала «репутацию» по числу загрузок. Это не значит, что с файлом что-то не так.

**Что сделать:**

1. В окне SmartScreen нажмите **«Подробнее»**
2. Нажмите **«Выполнить в любом случае»**

Если антивирус удалил файл, добавьте его в исключения и скачайте заново.

Исходный код лаунчера открыт, сборка публичная — проверить можно что угодно.

</details>

### 🍏 macOS

1. Скачайте `.dmg`, откройте и перетащите **NoteBuns** в **Программы**
2. **Первый запуск:** нажмите на приложение **правой кнопкой** (или Control + клик) → **«Открыть»** → в диалоге ещё раз **«Открыть»**

Обычный двойной клик в первый раз не сработает — так устроена защита macOS для приложений не из App Store.

<details>
<summary><b>⚠️ «Приложение повреждено» или «не удалось проверить разработчика»</b></summary>

<br>

Откройте **Системные настройки → Конфиденциальность и безопасность**, пролистайте вниз — там будет строка про NoteBuns и кнопка **«Всё равно открыть»**.

Если не помогло, откройте Терминал и выполните:

```bash
xattr -cr /Applications/NoteBuns.app
```

Команда снимает метку «скачано из интернета», больше ничего не делает.

</details>

### 🐧 Linux

Скачайте `.AppImage`, разрешите запуск и стартуйте:

```bash
chmod +x NoteBuns-x86_64.AppImage
```

```bash
./NoteBuns-x86_64.AppImage
```

<details>
<summary><b>⚠️ AppImage не запускается</b></summary>

<br>

Чаще всего не хватает FUSE. На Ubuntu и Debian:

```bash
sudo apt install libfuse2
```

Либо запустите без FUSE:

```bash
./NoteBuns-x86_64.AppImage --appimage-extract-and-run
```

</details>

## 🆘 Что-то пошло не так

- **Игра не запускается** — откройте «Настройки» и проверьте выделенную память, для сборки нужно от 5 ГБ
- **Мало места на диске** — в настройках можно перенести папку игры на другой диск
- **Не заходит на сервер** — проверьте, что лаунчер обновился до последней версии
