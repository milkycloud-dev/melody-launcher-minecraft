# NoteBuns Launcher

Официальный лаунчер сервера **NoteBuns**. Скачал, ввёл ник, нажал «Играть», остальное лаунчер сделает сам.

**[⬇️ Скачать последнюю версию](https://github.com/milkycloud-dev/melody-launcher-minecraft/releases/latest)**

---

## Что умеет

- Java уже внутри, ставить ничего не нужно
- При обновлении скачивается только то, что изменилось
- Бинды, шейдеры и ресурспаки остаются на месте
- Настройки модов (Voice Chat, эмодзи и других) переживают обновление сборки
- Лаунчер обновляется сам, без консольных окон
- Объём памяти подбирается под вашу систему
- Папку игры можно перенести на другой диск без потери файлов
- Есть защита от читерских текстур
- Работает на Windows, macOS и Linux

## Установка

### Windows

Скачайте `.exe` и запустите. Ярлык появится на рабочем столе.

<details>
<summary><b>Появилось окно «Windows защитила ваш компьютер» (SmartScreen)</b></summary>

<br>

Так бывает у новых программ, которые Windows видит впервые: у них ещё нет «репутации» по числу загрузок. Это не значит, что с файлом что-то не так.

**Что сделать:**

1. В окне SmartScreen нажмите **«Подробнее»**
2. Нажмите **«Выполнить в любом случае»**

Если антивирус удалил файл, добавьте его в исключения и скачайте заново.

Исходный код лаунчера открыт, сборка публичная, проверить можно что угодно.

</details>

### macOS

1. Скачайте `.dmg`, откройте и перетащите **NoteBuns** в **Программы**
2. **Первый запуск:** нажмите на приложение **правой кнопкой** (или Control + клик), выберите **«Открыть»** и в диалоге ещё раз **«Открыть»**

Обычный двойной клик в первый раз не сработает: так устроена защита macOS для приложений не из App Store.

<details>
<summary><b>«Приложение повреждено» или «не удалось проверить разработчика»</b></summary>

<br>

Откройте **Системные настройки > Конфиденциальность и безопасность** и пролистайте вниз. Там будет строка про NoteBuns и кнопка **«Всё равно открыть»**.

Если не помогло, откройте Терминал и выполните:

```bash
xattr -cr /Applications/NoteBuns.app
```

Команда снимает метку «скачано из интернета», больше ничего не делает.

</details>

### Linux

Скачайте `.AppImage`, разрешите запуск и стартуйте:

```bash
chmod +x NoteBuns-x86_64.AppImage
```

```bash
./NoteBuns-x86_64.AppImage
```

<details>
<summary><b>AppImage не запускается</b></summary>

<br>

Чаще всего не хватает FUSE. На Ubuntu и Debian:

```bash
sudo apt install libfuse2
```

Либо запустите без FUSE:

```bash
./NoteBuns-x86_64.AppImage --appimage-extract-and-run
```

</details>

## 🆘 Что-то пошло не так

- **Игра не запускается.** Откройте «Настройки» и проверьте выделенную память, для сборки нужно от 5 ГБ
- **Мало места на диске.** В настройках можно перенести папку игры на другой диск
- **Не заходит на сервер.** Проверьте, что лаунчер обновился до последней версии

Если не помогло, пишите в **[Telegram](https://t.me/notebuns_minecraft)** или **[Discord](https://discord.gg/KZhbk2UeQz)**.
