## 🚀 Возможности лаунчера

### ⚡ Автоматическое обновление
Лаунчер сам проверяет новые версии при каждом запуске и предлагает обновиться — вам не нужно ничего делать вручную.

### 📦 Автоматическая установка сборки
После первого запуска лаунчер автоматически скачивает и устанавливает всю игровую сборку (NeoForge + ~97 модов). Просто нажмите «Играть» и ждите — всё произойдёт само.

### ✅ Проверка целостности файлов
Лаунчер проверяет каждый файл по SHA-256 контрольной сумме. Если что-то повреждено — автоматически скачивается заново.

### 🔧 Умное управление памятью
Лаунчер автоматически определяет объём вашей оперативной памяти и выставляет оптимальные настройки. Вы можете изменить их вручную в настройках.

### 🖥️ Настройки разрешения и режима экрана
Выбирайте разрешение окна игры и полноэкранный режим прямо из лаунчера — без редактирования конфигов вручную.

### 📁 Выбор папки установки
Не хватает места на системном диске? Выберите любую папку для установки игры (например, другой диск).

### 🔄 Починка и переустановка
Кнопка «Проверить целостность» исправляет повреждённые файлы. Кнопка «Сброс и переустановка» полностью перекачивает сборку с нуля.

### 📋 Краш-репорты
При вылете игры лаунчер автоматически отправляет отчёт команде, чтобы проблема была быстрее исправлена. Эту функцию можно отключить в настройках.

## 🪟 Установка на Windows

1. Скачайте файл **`NoteBuns-Portable-v4.4.0.exe`** из раздела [Releases](https://github.com/milkycloud-dev/melody-launcher-minecraft/releases/latest)
2. Запустите скачанный `.exe` файл
3. Если Windows SmartScreen показывает предупреждение — нажмите **«Подробнее»** → **«Всё равно запустить»**
4. Лаунчер откроется и начнёт установку — просто нажмите «Играть»!

---

## 🍏 Установка на macOS

1. Скачайте файл **`.dmg`** для вашего процессора (Intel или Apple Silicon M1/M2/M3)
2. Дважды кликните по `.dmg` файлу — откроется окно установщика
3. Перетащите **NoteBuns.app** в папку **Программы (Applications)**
4. **Первый запуск**: найдите NoteBuns в папке «Программы», нажмите **правой кнопкой мыши** → **«Открыть»** → подтвердите **«Открыть»**
5. Если macOS всё равно блокирует: откройте **Системные настройки → Конфиденциальность и безопасность** → нажмите **«Всё равно открыть»**
